# RRNEWS Website

This is a ready to publish starter website for RRNEWS.

## What this folder contains

- `index.html`: The main website entry file
- `package.json`: The file that tells Vercel how to build the website
- `src/App.jsx`: The website content and structure
- `src/index.css`: The website design and styling
- `src/main.jsx`: The React starter file

## How to publish it for free

1. Create a free GitHub account.
2. Create a new repository called `rrnews-website`.
3. Upload all the files from this folder to that repository.
4. Create a free Vercel account.
5. In Vercel, click Add New Project.
6. Select your GitHub repository.
7. Click Deploy.
8. Vercel will give you a free website link.

## How to edit basic text

Open `src/App.jsx`.

You can change:
- News titles
- Category names
- Contact email
- Footer text
- Video titles

## How to edit colors

Open `src/index.css`.

The main red color used is:

`#b91c1c`

The dark background color is:

`#09090b`

## Important note

This is a front end website. It does not yet have an admin panel where you can post articles from a dashboard. That can be added later.
